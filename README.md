# MRCODEXMAYYO Portfolio

A responsive, single-page creative portfolio with a dark editorial look, lime accents, image-led project cards, and a contact form.

## Preview locally

Open `index.html` in a browser, or run a small local server from this folder:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Personalize before publishing

- Replace the sample project names and descriptions in `index.html` with your own work.
- Update the Instagram and LinkedIn links to your profiles.
- In `script.js`, replace `hello@yourdomain.com` with the email address that should receive contact messages. The form opens the visitor's default email app; it does not send messages through a backend.
- Update the about text and service offerings to match you.

Portfolio photos are loaded from Unsplash URLs and require an internet connection.
